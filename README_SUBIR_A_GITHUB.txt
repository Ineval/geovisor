INSTRUCCIONES IMPORTANTES

1. En tu repositorio de GitHub Pages debes subir DIRECTAMENTE estos archivos en la raíz del repositorio geovisor:

index.html
styles.css
script.js
logo.png
.nojekyll

2. NO subas la carpeta completa. Abre la carpeta y sube los archivos sueltos.

3. En GitHub debe verse así:
https://github.com/INEVAL/geovisor/blob/main/index.html
https://github.com/INEVAL/geovisor/blob/main/styles.css
https://github.com/INEVAL/geovisor/blob/main/script.js

4. Luego revisa estas URLs en el navegador:
https://ineval.github.io/geovisor/styles.css
https://ineval.github.io/geovisor/script.js

Si una de esas URLs dice 404, el archivo no está en la raíz del repositorio o no se publicó todavía.

5. Recarga con Ctrl + F5.
